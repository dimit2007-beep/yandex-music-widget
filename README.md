# Виджет Яндекс Музыки (рабочий стол Windows)

Компактная плашка поверх всех окон: показывает трек, который играет **на любом
твоём устройстве** (телефон, колонка, браузер), и управляет им.

## Запуск

```
npm start
```

(в новой консоли, где `node` виден в PATH)

## Что умеет

- 🔒 Фрилесс-окно поверх всех окон, перетаскивается мышью (за пустые места)
- 🎵 Обложка, название трека, исполнитель, бегущий прогресс-балл, время
- ♡ Лайк / снять лайк
- ⏮ ▶ ⏸ ⏭ Пауза, игра, следующий, предыдущий
- 🕒 Отдельный виджет часов (ЧЧ:ММ 24ч) со своей прозрачностью и фиксацией
- 🗘 Трей и ПКМ по плашке: показать/скрыть, кнопки вкл/выкл, прозрачность 0–100%,
  «Зафиксировать положение», «Перезапустить Яндекс Музыку», вход, сброс токена, закрыть
- 🖥 На рабочем столе виджет интерактивен, поверх приложений — клик-сквозь
  (кроме кнопок плеера, они всегда живые)
- ↔ Размер и позиция обеих плашек запоминаются автоматически

## Первый вход

1. Развёртываешь виджет (если закрыт — иконка в трее, правый клик).
2. На плашке нажимаешь «Войти через Яндекс».
3. Откроется окно входа Яндекса — авторизуешься и «Разрешить».
4. Токен перехватится автоматически и сохранится в `%APPDATA%\yandex-music-widget`.

Токен хранится только на твоём компьютере.

## Как это работает

- **Ynison** (`wss://ynison.music.yandex.ru`) — реальный протокол синхронизации
  устройств Яндекс Музыки. Мы подключаемся «теневым» устройством и слышим
  всё, что играет в любом другом клиенте твоего аккаунта.
- **REST API** (`api.music.yandex.ru`) — мета-данные трека и лайки.
- Управление плеером работает как пульт через Ynison (как «Пульт»
  в приложении Яндекс Музыки).

## Управление плеером: нюанс

Команда (пауза / следующий / лайк) отсылается тому устройству, которое
**активно играет в аккаунте**. Лучше всего управляется веб-плеер
(music.yandex.ru) и официальное приложение. На колонках с Алисой
команды пульта могут не применяться — там нужен другой сервис
(Yandex Station / Ynison-integration Home Assistant).

## Автозапуск (по желанию)

Включить автозапуск вместе с Windows:

```
node -e "require('electron')" -  # заглушка
```

Выполни в консоли из папки виджета:

```powershell
# пример автозапуска через реестр (путь подставь свой)
New-ItemProperty -Path "HKCU:\Software\Microsoft\Windows\CurrentVersion\Run" `
  -Name "YMMusicWidget" `
  -Value "D:\dev\ии-тест\yandex-music-widget\node_modules\electron\dist\electron.exe D:\dev\ии-тест\yandex-music-widget" `
  -PropertyType String -Force
```

## Файлы

- `main.js` — окна (виджет + часы), трей, OAuth, IPC
- `ynison.js` — Ynison-клиент (WebSocket), текущий трек + команды
- `ym-api.js` — REST API (мета-данные, лайки)
- `renderer.js`, `index.html`, `styles.css` — плашка
- `clock.html`, `clock.css`, `clock-renderer.js`, `preload-clock.js` — часы
- `preload.js` — мост между окном и главным процессом
